# style-guide-archives-government-h-r

Government, transit, wayfinding, Olympic and institutional identity and graphics manuals, organisations H to R.

This repository is one part of the [Style Guide Archives](https://github.com/WPTK/style-guide-archives), a public collection of style guides from around the world.

- **162 guides, 2.00 GB**
- Layout: `<category>/<organisation>/<year>-<title>.pdf`
- [INDEX.md](INDEX.md) lists every file with its year, size and the page it came from
- The full catalog, with leads for guides not archived yet, is [CATALOG.md](https://github.com/WPTK/style-guide-archives/blob/master/CATALOG.md)

## Cloning

```
git clone https://github.com/WPTK/style-guide-archives-government-h-r.git
```

## Large files

1 files of 100 MB or more are stored with [Git LFS](https://git-lfs.com). Run `git lfs install` once before cloning, or `git lfs pull` afterwards. Without it those files appear as small text pointers.
